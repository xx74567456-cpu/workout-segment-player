# 运动分段跟练（fit-segment）

一个纯前端的运动视频分段循环跟练工具。把健身视频按动作手动切分成若干段，跟练时逐段循环播放、自动倒计时、打卡记录，适合在家跟着视频练。

## ✨ 功能

- **本地导入视频**：视频以 Blob 存进 IndexedDB，全程不上传，离线可用
- **手动切分动作段**：拖动进度条在任意位置切分、重命名、删除分段
- **分段循环跟练**：每段独立循环，动作间可设休息倒计时、重复次数、整组轮数、AB 区间循环、画面镜像
- **分段模板分享**：把切分结果导出成 JSON 模板，别人导入即可套用同一视频的切分，省去手动分割
- **打卡记录**：练完打卡，按天/周/视频统计，含热力图、里程碑
- **数据管理**：搜索排序、批量管理、一键导出/导入完整备份
- **深色模式**、**全屏放大**（横屏自动铺满）

## 🛠 技术栈

- Vue 3 + Vite
- Capacitor（可打包安卓 / iOS 原生应用）
- IndexedDB（本地存储）+ vite-plugin-pwa（离线 PWA）

## 📱 本地开发

```bash
npm install
npm run dev        # 开发
npm run build      # 构建
npm run build:android  # 构建安卓（base 相对路径）
```
